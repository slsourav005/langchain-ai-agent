# LangChain AI Agent with Tools and Conversational Memory

An interactive AI agent built using Python, LangChain and Groq API. The agent can use external tools to perform calculations, retrieve weather information, answer technical questions and maintain conversational context.

## Features

- Groq API integration
- Calculator tool
- Weather information tool
- AI knowledge-base tool
- Conversational memory
- Gradio chatbot interface

## Tech Stack

- Python
- LangChain
- Groq API
- Gradio

## How to Run

1. Open the notebook in Google Colab.
2. Install the required dependencies.
3. Configure your Groq API key.
4. Execute the notebook cells in order.
5. Launch the Gradio interface.

## Project Status

Initial implementation completed. Future improvements include live weather API integration, persistent memory and document-based RAG retrieval.
